# Digital Library - المكتبة القانونية

مشروع مكتبة رقمية الادارة التنفيذية للشؤون القانونية مبني بـ React + Vite + Tailwind CSS مع دعم اللغتين العربية والإنجليزية.

## المميزات

- 🔐 نظام تسجيل دخول آمن
- 🌐 دعم اللغتين العربية والإنجليزية مع تبديل تلقائي للاتجاه (RTL/LTR)
- 📚 عرض الاستشارات القانونية في شكل بطاقات أنيقة
- 🛡️ حماية الصفحات للمستخدمين المسجلين فقط
- 🎨 تصميم مودرن وفخم يناسب الشركات
- 📱 متجاوب مع جميع الأجهزة

## بيانات تسجيل الدخول

- **اسم المستخدم:** WASAN
- **كلمة المرور:** 0000

## التقنيات المستخدمة

- **React 19** - مكتبة واجهة المستخدم
- **Vite** - أداة البناء السريعة
- **Tailwind CSS** - إطار عمل CSS
- **React Router** - التوجيه في التطبيق
- **i18next** - الترجمة والدولنة
- **Google Fonts (Tajawal)** - خط عربي أنيق

## التشغيل

```bash
# تثبيت التبعيات
npm install

# تشغيل المشروع في وضع التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

**ملاحظة:** المشروع يستخدم Tailwind CSS عبر CDN لضمان عمل التصميم بشكل صحيح.

## هيكل المشروع

```
src/
├── components/          # المكونات المشتركة
│   ├── Header.jsx      # شريط التنقل
│   ├── LanguageSwitcher.jsx  # تبديل اللغة
│   └── ProtectedRoute.jsx    # حماية الصفحات
├── pages/              # صفحات التطبيق
│   ├── Login.jsx       # صفحة تسجيل الدخول
│   ├── Home.jsx        # الصفحة الرئيسية
│   ├── Library.jsx     # صفحة المكتبة
│   └── ConsultationDetails.jsx  # تفاصيل الاستشارة
├── i18n/               # ملفات الترجمة
│   ├── index.js        # إعداد i18n
│   ├── ar.json         # النصوص العربية
│   └── en.json         # النصوص الإنجليزية
├── data/               # البيانات
│   └── fakeData.js     # البيانات التجريبية
└── App.jsx             # المكون الرئيسي
```

## الصفحات

### الصفحة الرئيسية (`/`)
- تصميم أنيق ومهني للمكتبة القانونية
- شعار جميل مع أيقونات قانونية
- وصف شامل للمكتبة ومميزاتها
- نافذة منبثقة لتسجيل الدخول
- ألوان مناسبة للمكتبة القانونية (أزرق داكن ورمادي)

### صفحة تسجيل الدخول (`/login`)
- نموذج تسجيل دخول أنيق
- التحقق من بيانات ثابتة
- رسائل خطأ واضحة
- زر تبديل اللغة

### لوحة التحكم (`/dashboard`)
- ترحيب بالمستخدم
- وصف المشروع
- روابط سريعة للمكتبة

### صفحة المكتبة (`/library`)
- عرض الاستشارات القانونية في شكل بطاقات
- معلومات التصنيف والتاريخ
- زر عرض التفاصيل

### صفحة تفاصيل الاستشارة (`/consultation/:id`)
- عرض كامل للاستشارة
- الاستشارة القانونية والرأي القانوني
- زر العودة للمكتبة

## التخصيص

يمكنك تخصيص المشروع من خلال:

1. **تعديل البيانات:** تحديث `src/data/fakeData.js`
2. **تغيير التصميم:** تعديل فئات Tailwind في المكونات
3. **إضافة ترجمات:** تحديث ملفات `src/i18n/`
4. **تعديل بيانات الدخول:** تحديث `src/pages/Login.jsx`
